# Helpメニュー

Helpメニューは、メイン画面と**Analysis Mode**の両方にあります。

| 項目 | 内容 |
|---|---|
| Update available: v… | 新しい版が見つかったときだけ表示されます。選ぶと更新のダイアログが開きます |
| Check for Updates… | 新しい版があるかを今すぐ確認します |
| Check for Updates on Startup | 起動時の自動確認のオン・オフ（既定はオン） |
| Open Log Folder | ログファイルのあるフォルダを開きます |
| About FluoRaPressée | バージョン、ユーザーデータの場所、このプロセスのログファイル名などを表示します |

## 更新の確認

起動から数秒後に、バックグラウンドでGitHub Releasesを確認します（**24時間に1回まで**）。
新しい版があると、メニューの名前が **Help (update available)** に変わり、先頭に「Update available: v…」が表示されます。
測定の開始を妨げないよう、ダイアログが自動で開くことはありません。
インターネットにつながらないなどで確認できなかった場合も、何も表示しません。

**Check for Updates…** で手動で確認した場合は、失敗するとその理由を表示します。

更新のダイアログには、新しい版の変更点（リリースノート）と次のボタンが表示されます。

- **Download FluoRaPressee-Setup-…exe**: インストーラーをブラウザでダウンロードします。
- **Open release page**: そのリリースのページをブラウザで開きます。

FluoRaPressée 自身がインストーラーをダウンロードしたり実行したりすることはありません。
ダウンロード後は、FluoRaPressée を終了してからインストーラーを実行してください（[更新の手順](../../installation.md#更新)）。
ソースから起動している場合は、ボタンの代わりに `git pull` で更新するよう表示されます。

ベータ版（バージョン番号に `b` や `rc` を含む版）を使っている場合は、次のベータ版も更新の対象になります。
正式版を使っている場合は、正式版だけが対象です。

確認のときにGitHubへ送るのは、ソフトウェア名（`FluoRaPressee-Updater`）だけです。

## ログファイル

インストール版はコンソール画面を持たないため、動作中のメッセージやエラーを**起動ごとに別のログファイル**に書き込みます。

```
<ユーザーデータの場所>\logs\app-<live|analysis>-<日時>-<プロセスID>.log
```

メイン画面（`live`）とAnalysis Mode（`analysis`）を同時に起動しても、それぞれ別のファイルになります。
30日より古いログと、新しいほうから数えて100個を超えたログは、起動時に自動で削除されます。

不具合を報告するときは、**About FluoRaPressée** に表示される「Log file」のファイルを添付してください。
ソースから起動している場合は、これまでどおりコンソールに表示され、ログファイルは作られません。

ユーザーデータの場所は[保存データの形式](../../data-formats/index.md#アプリが自動で保存するファイル)を参照してください。
